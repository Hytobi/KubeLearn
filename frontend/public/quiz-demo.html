Quel est le rôle principal d'un Pod dans Kubernetes ?

A. Gérer les permissions et la sécurité du cluster
B. Exécuter un ou plusieurs conteneurs partageant les mêmes ressources ✓
C. Router le trafic réseau entre différents services
D. Stocker les données de configuration du cluster

🎉 Bravo ! Bonne réponse !

Le Pod est la plus petite unité d'exécution dans Kubernetes. Il peut contenir un ou plusieurs conteneurs qui partagent le même réseau, le même stockage et les mêmes ressources.

Commandes utiles

Voici quelques commandes kubectl essentielles pour ce niveau :

$ kubectl get pods
$ kubectl describe pod <nom-pod>
$ kubectl logs <nom-pod>
$ kubectl delete pod <nom-pod>
$ kubectl run mon-pod --image=nginx
